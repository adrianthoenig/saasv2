# SaaS Landing Page – HTML & CSS Practice

This project is a **SaaS landing page** created as a practice exercise to improve **HTML and CSS** skills, with a strong focus on layout, responsive design, and clean styling.

The layout is inspired by a **public Figma design**, which was recreated manually without using CSS frameworks or JavaScript libraries.

---

## 🧠 Project Purpose

- Practice **semantic HTML**
- Improve **modern CSS** skills
- Work on **responsive design**
- Recreate a real-world UI from Figma
- Build a clean and well-structured front-end project

---

## 🛠️ Technologies Used

- **HTML5**
- **CSS3**
  - CSS Variables
  - Flexbox
  - Media Queries
- **Font Awesome** (icons)

> ❌ No frameworks  
> ❌ No JavaScript  
> ❌ No CSS preprocessors  

---

## 📱 Responsive Design

The landing page is fully responsive and optimized for:

- 📱 Mobile
- 💻 Tablet
- 🖥️ Desktop

A **mobile-first approach** was used, scaling the layout with media queries for larger screens.
